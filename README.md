# CommonKind

A community event platform that connects people with local volunteering opportunities. A little time. A real difference.

**Live website:** [CommonKind](https://b14-a8-client.vercel.app/)
**Backend API:** [CommonKind API](https://b14-a8-server.vercel.app/)

## Features

- Browse upcoming events and view event details.
- Create, edit, and delete your own events.
- Join events and manage your registrations.
- Register and log in with email or Google.
- View and update your profile.
- Responsive design, light/dark themes, and toast notifications.

## Tech Stack

- **Frontend:** Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui.
- **Authentication:** Better Auth, MongoDB adapter, and JWT.
- **Backend:** Express.js, MongoDB, and JavaScript.
- **Deployment:** Vercel.
